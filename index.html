AC-Type 2-laadpalen (live koppeling nog niet actief) Er is nog geen live laadpaalbron gekoppeld. De app kan daarom nog geen actuele prijzen, beschikbaarheid of de goedkoopste drie laadpalen tonen. Er worden geen laadpalen verzonnen. Ververs laadpalen Criteria: openbare AC-Type 2-aansluiting, beschikbaar, maximaal 300 meter lopen van het eindadres; sorteren op totaal tarief (Shuttel indien bekend). Automatisch opnieuw controleren bij circa 5 km vóór aankomst is nog niet actief: daarvoor zijn een live laadpaalprovider en een actieve locatievoorziening op de iPhone nodig. Beschikbaarheid bij aankomst kan nooit worden gegarandeerd. 5. Google Maps instellen Google Maps API-sleutel Google Maps verbinden Sleutel wissen Google Maps nog niet verbonden. Voor automatisch afstand berekenen gebruikt deze versie de Google Maps JavaScript API met Routes. Adressuggesties werken zodra ook Places is ingeschakeld. Google Cloud vereist doorgaans facturering; gebruik API- en websitebeperkingen. Een lokaal HTML-bestand is minder geschikt voor beveiligde websitebeperkingen: publiceer de app bij voorkeur op een eigen HTTPS-adres. De sleutel wordt uitsluitend lokaal in deze browser opgeslagen en niet in GitHub gepubliceerd. Gebruik altijd website- en API-beperkingen; een browsersleutel is niet volledig geheim. Een live laadpaalkoppeling is een aparte volgende stap; Google Maps biedt geen complete, gegarandeerde Shuttel-tarieven en realtime bezettingsinformatie voor alle laadpalen.
