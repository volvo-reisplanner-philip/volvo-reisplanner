4. Google-adressen automatisch aanvullen (optioneel)

Wil je bij vertrekadres en bestemming suggesties uit Google Maps krijgen? Dat kan met een Google Maps API-sleutel. De reisplanner werkt ook zonder deze functie.

Adresvoorstellen worden automatisch geactiveerd als er een sleutel is opgeslagen.

Beveiliging: de sleutel wordt alleen lokaal in deze browser opgeslagen en niet in GitHub gepubliceerd. Iedereen met toegang tot dit browserprofiel kan de sleutel mogelijk uitlezen. Een API-sleutel in een browser is niet geheim: beperk hem in Google Cloud tot Websites met jouw GitHub Pages-adres én tot de benodigde Maps-API's. Publiceer de sleutel nooit in GitHub. Google Maps-gebruik kan kosten veroorzaken; een budgetwaarschuwing is geen harde bestedingslimiet.

Opgeslagen bestemmingen en rekeninstellingen staan alleen in de opslag van deze browser. Andere apparaten delen dit adresboek niet automatisch.
